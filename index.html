RouteMind

Real-time fleet dispatch, built and benchmarked like a systems paper

Inspired by real-world ride-hailing platforms like Uber, this 7-service event-driven system solves real-time nearest-driver dispatch and routing challenges. It combines a hand-built Quadtree spatial index, Dijkstra + A* pathfinding, a from-scratch LRU cache, and a trained ML model for ETA prediction — every result independently benchmarked, not asserted.

+ What's actually custom-built here
  • Quadtree spatial index — hand-implemented, branch-and-bound k-NN search, kept in sync via Kafka rather than querying Redis on every dispatch.
  • Dijkstra + A* — both implemented over a weighted road graph; A* is primary, Dijkstra is an explicit correctness baseline and fallback, verified to produce identical path costs across 500 trials.
  • LRU route cache — HashMap + doubly linked list from scratch, not LinkedHashMap, for O(1) get/put.
  • ETA correction model — a trained GradientBoostingRegressor served from a separate Python microservice, called over REST with a timeout and graceful fallback.

FinSight AI

Autonomous financial intelligence agent, from ingestion to production deployment

A production-grade RAG + multi-agent system that ingests live news, SEC filings, and market data, coordinates three specialized agents to answer complex financial questions, and returns a fully structured, typed report in under 3 seconds — with a full MLOps pipeline behind it, not just a notebook.

+ What's actually custom-built here
  • Multi-agent orchestration — Risk, Sentiment, and Portfolio agents coordinated via LangGraph's explicit node/edge graph, each output validated by a Pydantic schema with automatic retry on malformed responses.
  • RAG pipeline — HuggingFace all-mpnet-base-v2 embeddings, chunked with overlap, indexed in FAISS and persisted to S3, with retrieval precision tracked in MLflow.
  • Continuous ingestion — Kafka pipeline pulling live news (NewsAPI), SEC filings (EDGAR), and market prices on a 5-minute cycle.
  • Automated drift detection — a daily Airflow DAG evaluates RAG precision and auto-retrains embeddings if it drops below threshold, no manual intervention.
  • Full observability — Prometheus + Grafana dashboards for latency, agent success rate, and retrieval precision; entire stack provisioned via Terraform on AWS EKS.
